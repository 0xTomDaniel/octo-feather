existing sandbox. No PID/mount/network isolation is removed or widened. The
actual server and both actual judge descendants open pidfds on themselves,

kernel handle through exec, observation and cleanup. Close-on-exec socket EOF
precedes handling the next registration. A readiness request from the actual
judge waits for both sleep registrations while they are live before the judge
returns, preventing a fast return from racing registration and changing killed
argv records. The final check requires every server dead and exactly one of
each actual escape descendant dead; missing observations fail closed.
