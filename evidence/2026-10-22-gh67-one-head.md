# qc and review in parallel on one head; status-only and clean-refresh checks (issue #67 items 8, 9, 10, ticket #88)

Smoke of the supervisor.md order change and the merge-ask check that carries it (docs/adr/0008). Owed eval: docs/owed-evals/67.md.

Removed: supervisor.md's serial order (the pilot's "code review of the head QC left", "then integrate and run `just qc` again" with no review, and the self-check's "the review verdict on the merge ask head, with only QC's status commit between them"); ADR 0022's "QC and review judge adjacent heads, not one ... the review judges H′ ... No further mechanism ties the two verdicts to one head"; `octo-feather-lane`'s `judged_check` (a row passed when only `qc: built` subjects followed its sha, files never read) and `verdict`'s rule that HEAD be the PR's current head (a review of H could not be posted once qc made H′).

## Changes

- `agents/supervisor.md`: Authority line on `just qc` now gives the order: integrate, then `just qc` and a fresh code review in parallel on that head H, then the merge ask (spec `#lanes-one-head`), and one line on the heavy budget: both heavy slots of the box's at-most-2, schedule other heavy work around it. The pilot path and the failed-criterion loop run qc and review again in parallel on the new head; the self-check asks for both verdicts on one judged head.
- `scripts/octo-feather-lane verdict PR HEAD REPORT`: HEAD is the head the review judged, any commit of the PR; the comment names `Head: <H>` and `PR head: <head when posted>`.
- `scripts/octo-feather-lane merge-ask PR --status FILE [--base REF]`: every row names one judged head H, the verdict comment's head must be H, and a new `Judged:` line must equal the proof the check computes from the lane worktree's git: H to the PR head H′ holds only `qc: built ... (judged <sha>)` commits changing only the `--status` files, and merges of BASE (default origin/main) whose tree is git's automatic merge (`git merge-tree --write-tree`) after which the lane's own diff against BASE, status files aside, is identical to its diff at H (same paths, same blobs both sides). Any other commit, file, conflict or branch fails, named.
- ADR 0022 corrected in place; GLOSSARY.md: code review is QC on code, not QA.
