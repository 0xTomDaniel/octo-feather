## Spawn, and a background job in the agent's scope

`herdr-spawn --workspace w81 --name scratch-park-1001 --label scratch-park --role general-worker --cwd <worktree>`
printed `tab=w81:tG pane=w81:pG ... provider_session_id=02595285-7f99-4b80-bc92-5fb8231b2191`.
`herdr pane process-info --pane w81:pG`: shell 1285795, foreground `pi` 1285834; the shell's
cgroup `.../app.slice/octo-feather-agent-w81:pG-1411777f.scope`. The agent was asked through
`herdr-say` to run `setsid sleep 900 </dev/null >/dev/null 2>&1 &` with its bash tool; it went
`done` and the scope's `cgroup.procs` then held `1285795 /bin/bash`, `1285834 pi ...`,
`1286177 sleep 900`.

```

```

Session, role, parent and cwd match the spawn (`parent` the spawning pane w81:pF). The workspace
had other tabs, so only the tab closed. `killed=0`: the tab close had already ended the shell
and Pi when the scope was stopped.
