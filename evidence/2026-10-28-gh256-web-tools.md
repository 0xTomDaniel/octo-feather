# gh256: web tools for the roles listing web (issue #256, ticket #262)

Change (1ca94ab): web-mcp.json, the kit's one web server list (Parallel, Exa, keyless); extensions/web-servers.ts registers it; scripts/pi-role gives a role listing `web` that extension, one `mcp__<server>__*` tools entry per server, and no `--no-mcp`. agents/director.md, agents/implementer.md, agents/corrector.md, agents/code-reviewer.md add `web` to `tools:`. tests/web-tools.sh covers the launch with real Pi 1.3.0 and stub servers; the runs below are live, real servers and real models.

Prompt for each run: `Use your web search tool to find the GitHub repository of the smol-toml library and reply with its URL only`. Single samples, no variance claim.

Smoke: agents/implementer.md (`scripts/pi-role agents/implementer.md -p <prompt>`: printed https://github.com/squirrelchat/smol-toml, 8.9 s)
Smoke: agents/director.md (`scripts/pi-role agents/director.md -p --mode json <prompt>`: tools read bash grep find ls mcp__exa__web_search_exa mcp__exa__web_fetch_exa mcp__parallel__web_search mcp__parallel__web_fetch, no edit or write; called mcp__exa__web_search_exa, replied the smol-toml URL)
Smoke: agents/corrector.md (`scripts/pi-role agents/corrector.md -p --mode json <prompt>`: exit 0, 8.8 s, called mcp__exa__web_search_exa `{"query": "smol-toml GitHub repository TOML parser", ...}`, final https://github.com/squirrelchat/smol-toml; plain `-p` demo printed the same URL, exit 0)
Smoke: agents/code-reviewer.md (`scripts/pi-role agents/code-reviewer.md -p --mode json <prompt>`: exit 0, 18.5 s, called mcp__exa__web_search_exa `{"query": "smol-toml library GitHub repository", ...}`, final https://github.com/squirrelchat/smol-toml)
Removed: `--no-mcp` from scripts/pi-role's launch for the four roles listing web (every other role keeps it). Incident: #256 owner ask; agents reinvent libraries without searching for one (#254, templates/typescript toml.ts #136), and a role launched with `--no-mcp` had no web tool to search with.

Base (2e1f97d, the lane's base main commit): the same roles launch with `--no-mcp` and no `mcp__*` tools, so none of these prompts can call a web search tool there. The fail-before, pass-after eval cases are owed: docs/owed-evals/256.md.
