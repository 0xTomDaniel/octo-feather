# gh503: a TypeScript-born repo's gate run as one trend line; its gate budget in the report and the merge ask (#556)

Change (ticket #556, lane gh503, T10): the TypeScript template's `just check` is one Vitest run whose `gate` project
(tests/gate.test.ts) runs each GATE_RECIPES recipe as a command, beside the integration and e2e tests; a Vitest
reporter (tests/trend-reporter.ts, Vitest's own reporter API) appends one check-runs.jsonl line per run in the format
the kit's tests/gate/conftest.py owns, tier `full` only when the run narrowed nothing; `gate-budget.toml` at its root.

Drive criterion `comms#acceptance-report-gate-budget`, features/README.md index line, the drive).
