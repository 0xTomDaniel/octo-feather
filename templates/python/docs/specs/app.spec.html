App

The starter spec of this repository: its one command, app hello. Shape new behavior here, or in a new spec beside it.

User stories

As a user, I greet someone by name from the terminal and can read the result as JSON.

Acceptance criteria

Given a user with the app installed, When they run app hello with a name and --json, Then the command exits 0 and prints one JSON document holding the name and its greeting.

Modular boundaries

The app owns the greeting. Caller-facing seam: the app CLI. Dependency direction: self-contained. Observable scope: the command's stdout, stderr and exit code.
