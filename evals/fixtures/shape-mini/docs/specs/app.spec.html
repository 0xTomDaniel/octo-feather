Greeting

As a script author, I greet a name with app hello NAME and read the greeting as JSON, so I never parse text.

app hello NAME prints Hello, NAME, the name trimmed. With --json it prints {"name": NAME, "text": "Hello, NAME"} (ADR 0001).

A name blank after trimming is an error: exit 2, and with --json {"error": "name must not be empty"}.

Given a name, When a script runs app hello Ada --json, Then it reads {"name": "Ada", "text": "Hello, Ada"}.
