Greet

The app greets people from its CLI.

Acceptance

Given a name, When app hello Ada runs, Then it prints Hello, Ada and exits 0.

Given a name, When app hello Ada --json runs, Then it prints {"name": "Ada", "text": "Hello, Ada"}.

Given a name, When app hello Ada --shout runs, Then it prints HELLO, ADA; with --json the text field is upper-cased.

Given a name and N, When app hello Ada --times N runs, Then it prints the greeting N times, one per line; N below 1 exits 2 with an error.
