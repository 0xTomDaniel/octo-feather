octo-feather specifications

docs / specs / index.spec.html

Canonical behavior for the octo-feather kit. These HTML pages are the specs, with no Markdown twin (ADR 0006). Lasting decisions are the ADRs; terms are in GLOSSARY.md; where a spec and an ADR differ, the ADR wins until the spec is fixed.

User stories

As the owner or an agent, I open one index and reach every octo-feather spec, decision record and the glossary.

Acceptance criteria

Given the owner, When the owner opens the spec index, then follows each spec link, Then every spec in the collection opens, and the index lists each one once.

Modular boundaries

The index owns listing the spec set, the ADRs and the glossary, one line each. Caller-facing seam: this page's links. Dependency direction: self-contained; the index depends on the pages it links and no page depends on it. Observable scope: the links on this page.
