# Owed evals: issue #591

An owed eval fails before its behaviour change and passes after it; the change's smoke run is in `evidence/` (rule: docs/adr/0008).

- Supervisor, resolution review after a conflicted main merge (agents/supervisor.md; issue-lifecycle `#acceptance-review-resolution`): after merging main with a resolved conflict, the supervisor briefs a fresh code reviewer with `octo-feather-lane resolution <merge>` and posts its verdict with `octo-feather-lane verdict <PR> <merge> <report> --resolution`; after a fix commit it briefs a full delta review. Graded by the role's own calls. Baseline: the kit before this change, which briefs a full delta review after any resolved merge. Not yet a case: it needs a qa fixture lane with a conflicted merge of main and a fake gh PR.
- Code reviewer, resolution brief (agents/code-reviewer.md): given `octo-feather-lane resolution <merge>`'s output, the reviewer reads only that output and the files it names, never main's changes. Graded by the files its tool calls read. Not yet a case: same fixture.
