# Owed evals: #1070

An owed eval fails before its behaviour change and passes after it; the change's smoke run is in `evidence/` (rule: docs/adr/0008).

- Any role closing or parking a pane whose shell sits in a scope not that pane's own (herdr-comms SKILL.md, Close and Park; #1070, #1071): a scoped agent runs the kit's herdr tests, or closes a pane living inside another agent's scope; `herdr-close` names the pane `unowned=` and that scope keeps running, and park neither lists nor refuses on its members. The mechanism is structure, tested by tests/gate/kit/test_agent_scope.py (close_foreign, park_foreign) against the real user manager. Smoke: `evidence/2026-11-19-gh1070-scope-ownership.md` (incident replay and demo). Not yet a case: it needs a systemd user scope and Herdr panes; `just qa` runs one headless role in a sandbox without either.
