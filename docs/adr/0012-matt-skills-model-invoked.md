# Matt's workflow skills are model-invoked

mattpocock/skills marks its workflow skills `disable-model-invocation: true`, so only a slash command can start them. In octo-feather the agents run the workflow, so each vendored one (implement, implement-spec, to-tickets, grill-with-docs) and pstack's `correct` gets a patch line removing that flag. They are vendored at exact pins through the `Skillfile` (mattpocock/skills@49dd158, cursor/plugins@0b8e952), with patches in `.skillfile/patches/skills/<name>/` whose first line names the reason; each patch changes only what an ADR needs. grill-with-docs and the grilling and domain-modeling skills it calls serve shaping, which happens outside the factory (ADR 0021). handoff, to-spec, triage and improve-codebase-architecture are not vendored, because no role uses them. Upstream's "call the Skill tool" wording is kept: Pi models load the named skill. Pollution is contained because every role loads only the skills its role file lists (ADR 0016). Decided by Tom, 2026-10-18.
