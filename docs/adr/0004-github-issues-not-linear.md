# GitHub Issues is the tracker

Work items are GitHub issues: each lane has one parent issue, and its tickets are sub-issues of it (ADR 0019). Lane keys are `gh<number>`, and every tracker step is a `gh` call. The tracker lives beside the code and needs no second account or API. Tom: "no linear, we'll use github issues to keep it simple", 2026-10-18.
