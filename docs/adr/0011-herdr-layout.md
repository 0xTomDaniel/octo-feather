# Herdr layout: a director workspace, then one workspace per lane

Herdr holds one workspace `director` with a single tab for the director. Every lane gets its own workspace named by its lane key (`gh<issue>`): the first tab, `supervisor`, is the supervisor, and each worker gets its own tab in that workspace: `worker-1`, `worker-2`, the per-merge `code-reviewer`, and in a correction lane the `corrector` (ADR 0020). Integration is a script, so it has no tab (ADR 0017). One agent per tab, one pane per tab: a split pane is never needed because nobody watches two agents at once, and a second pane only makes `herdr-say` targeting ambiguous. A one-shot run that needs no conversation, such as a judge, may run headless through `pi-role -p` instead of in a tab (ADR 0016). Layout by Tom, pane rule by Exo, 2026-10-18.
